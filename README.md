# Mimir 미미르

폰 안에서 작은 AI 모델을 돌려, 직접 깨운 **리플**(봇)들과 대화하는 안드로이드 앱입니다.
세계수 뿌리 아래 샘에 사는 지혜의 요정 미미르가 샘물을 길어 올리면, 물결에서 말과 생각을 지닌 리플들이 태어나요.
[Yddrasil 요정 시리즈](https://morph-house-github-io.pages.dev/)(Wisp · Flit · Irisa Bridge)의 네 번째 요정입니다.

> 이 저장소에는 **배포 파일(APK)만** 올라옵니다. 소스 코드는 공개하지 않습니다.

## 주요 기능

- **샘에서 깨우기**: 이름·성품·말씨·첫인사를 정해 나만의 리플을 만들어요. 샘플 문구로 바로 시작할 수 있어요.
- **물가**: 리플과 이야기해요. 대답이 글자 단위로 차올라요.
- **샘물 받기**: 추천 AI 모델을 앱 안에서 받아요. 내 폰 메모리에 맞는지 알려 줘요.
- **다른 앱에서 부르기**: Wisp 같은 앱이 리플을 불러 대화에 쓸 수 있어요. 처음 보는 앱은 알림으로 허락할지 물어봐요.
- **샘 깨워 두기**: 미미르가 화면 뒤에 있어도 다른 앱의 부름에 대답해요.

## 대화는 폰 안에서만

리플과 나눈 대화는 **폰 밖으로 나가지 않아요.** 서버나 유료 AI 서비스를 쓰지 않고, 폰 안에서 모델이 직접 대답해요.
인터넷은 샘물(모델)을 받을 때와 광고를 보여 줄 때만 써요.

## 내려받기

[Releases](../../releases) 페이지에서 최신 버전의 APK를 받으세요.

## 설치 방법

1. Releases 에서 `.apk` 파일을 휴대폰으로 내려받습니다.
2. 파일을 열면 "출처를 알 수 없는 앱 설치" 허용을 묻습니다. 허용해 주세요.
3. 앱을 열면 첫 화면의 **샘 준비** 안내를 따라 하세요.
   1. 샘물(모델) 받기: 약 1.4GB, 와이파이를 권해요
   2. 첫 리플 깨우기
   3. 물가에서 이야기하기

## 참고

- 안드로이드 8.0 이상, 64비트(arm64) 폰에서 동작해요. **메모리 6GB 이상**을 권해요.
- 모델을 받으려면 저장 공간이 2GB 정도 필요해요.
- 첫 대답은 모델을 불러오느라 몇 초에서 수십 초 걸릴 수 있어요.
- 기본 모델은 Kanana 1.5 2.1B (kakaocorp, Apache 2.0)예요. 모델은 앱에 들어 있지 않고, 앱 안에서 원본을 받아요.
- 지금은 미리보기 버전이에요. 기억의 책(문서 지식) 등 일부 기능은 아직 없어요.
